# ID OpenU

A small Chrome / Edge extension that remembers your **ID number** on the Open University of Israel login page and fills it in for you automatically.

Your browser already saves your username and password, but not the ID number. This extension handles the ID, so you don't have to type it every time.


## Privacy

- Your ID is saved **only on your own computer**, in the browser's extension storage.
- It is **never sent anywhere**. The extension makes no network requests.
- It only runs on `https://sso.apps.openu.ac.il/`.
- The ID is stored as plain text in the browser, so don't use it on shared or public computers.

## Install

1. Download this repository: click **Code → Download ZIP**, then unzip it.
2. Open `chrome://extensions` (or `edge://extensions`).
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the unzipped folder (the one that contains `manifest.json`).

## Use

- Log in once as usual. Your ID is saved automatically.
- From then on, the ID field on the login page fills itself in.
- Click the extension icon to view, change, or delete the saved ID.
